## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**这一版改了什么**

- **「+」菜单里多了「容器…」**：页签栏最右端那个「＋」点开，现在有「新建
  终端」「新建数据库连接…」「容器…」三项 ⇒ **不用再去「连接」菜单里找
  容器**。容器页已经开着就**切过去**，不会又开一个。
- ⚠️ 没连接时这一项是**灰的**（跟「新建终端」「新建数据库连接…」一样）——
  容器工作台复用**这条 SSH 连接**，没有连接就没法建。

**上一版（v0.9.1）的主要内容**

- **界面重做**：暗色主题分成窗底 / 面板 / 卡片三层，新增卡片、状态药丸、
  键帽、等宽四个可复用的原语；状态列改胶囊；数字右对齐、ID 与端口等宽；
  曲线圆角卡底 ＋ 渐变面积填充；欢迎页三张能力卡 ＋ 键帽化。
- **容器工作台审查项全部落地**：表格可排序、行有右键菜单与快捷键、空态错态
  是大号说明、日志可折行可复制全部、镜像 / 卷 / 网络能筛、终端搬进详情区。
- **编辑器可以停靠在三个位置**：主栏页签（默认，与终端并列）/ 底部 / 左右
  侧栏；页签标出文件在哪台机器上；打开 compose 文件时文件面板跳到项目目录
  并选中该文件。
- **容器文件页瘦身**：目录 / 文件 / 链接各有图标；权限用通用写法不翻译；
  工具条并成一行纯图标按钮。
- 修：Windows 本地路径的逐字前缀、Docker 没权限不说人话、软链图标在
  Adwaita 里不存在、点容器时底下挂着别的 compose 项目、容器里没有 `ls` 时
  甩 docker 原话。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- 图标主题没随包带 ⇒ 界面图标可能显示不出来，不影响功能。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 编辑器三停靠位 · 数据库工作台
（PostgreSQL / MySQL，通道复用当前 SSH 连接）· 容器工作台（日志 / 终端 /
监控 / 文件 / 镜像 / compose，复用同一条 SSH 连接）· 凭据库（argon2 +
AES-GCM）· 中英文界面 · 会话录制与回放（asciicast）· 串口会话。

## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**本版要点**

- **Linux 默认也并入「一台服务器一条 SSH 连接」**。上一版把连接中枢做了
  出来（文件面板、端口映射、数据库工作台共用一条连接），但 Linux 的终端
  还是 spawn 用户自己的 `ssh`；本版 libvte 后端也能走**进程内 SSH**了
  （程序自己开一对 pty：master 交给 libvte、slave 做桥接）⇒ **终端也并入
  共享连接**，连同一台服务器**密码只问一次**、只占服务器一个连接位。
  ⚠️ 并入后终端**不走你自己的 `ssh`** ⇒ `~/.ssh/config`（ProxyJump 等）与
  ssh-agent 不生效 ⇒ 需要的话在**首选项 →「终端」页 →「终端连接方式」**
  切回「spawn 自己的 ssh」（环境变量 `PP_TERM_SSH=inproc|spawn` 也能强制）。
- **结果网格「生成值…」**：结果里**右键一行** → 「生成值…」，选
  序列/自增、UUID、当前时间、当前日期、随机数 五种，实时预览。值由
  **数据库**算（序列必须数据库分配，客户端自己数会撞号；时间用**数据库
  的时钟**，客户端时钟可能跟库差几分钟），按方言分派（UUID / 随机数 PG
  与 MySQL 各用各的函数；序列 / 自增两家都用 `DEFAULT`，即列的默认值）。
  写进格子的是一条 `=` 开头的表达式，保存时库里存的是**数据库算出来的值**。
- **结果网格「列宽拖拽柄」**：抓住列头边缘就能拖，而且**记住你拖出来的
  宽度**（以前一刷新、一变窄就被自动重排冲掉）；列菜单里多了
  「恢复默认宽度」（拖过才出现）；换结果集时清掉。顺带修一个旧问题：
  藏过列之后，列头**右键**菜单会作用到别的列上。
- **ghostty 引擎补齐三件**（Windows 版的默认引擎；Linux 可在
  首选项 →「终端」页切换）：① 用户设的**回滚行数上限**真的生效了
  （以前内核只按字节限 ⇒ 设 10000 行形同虚设，几百 KB 输出就把历史挤掉）；
  ② **自定义配色**生效（首选项换配色方案，终端跟着变；远程程序自己改色
  （OSC）仍然以远程为准）；③ **录制（asciicast）可用**（以前行号语义与
  libvte 对不上，录出来的东西对不上）。顺带修：浅色方案下屏幕背景
  不跟着变。
  ⚠️ 录制的边界：输出超过回滚上限（默认 10000 行）之后，超出部分可能
  丢行（libvte 引擎以空行占位并如实计数；ghostty 引擎整段跳过）。

**上一版（0.6.0）的内容照旧**：数据库工作台对标 SQLite 客户端 dbx 重做一遍
——筛选就是一个宽 WHERE 框写完回车查、旁边 ▾ 条件助手按列类型转义；
工具条收回一行、底栏报账（行数·耗时·待保存 / 常驻当前 SQL / 统计总行数
真值）；表属性页多一段只读可复制的「建表语句」。

**再上一版（0.5.4 / 0.5.3）的内容照旧**：修堡垒机上分屏失败（回环目标
不查也不写 known_hosts）；连接中枢；修上传大文件时界面整体卡死
（只重画正在传的那一行 + 传输走自己的通道）+ 传输队列角标重做。

**Windows 版的已知差异**：

- 终端默认并入共享连接（本版起 Linux 也一样）：不走你自己的 `ssh` ⇒
  `~/.ssh/config`（别名、ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己
  的 ssh」在首选项里切（Linux 有 VTE / ghostty 两种引擎可选；Windows
  没有 VTE，只有 ghostty）；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- 图标主题没随包带 ⇒ 界面图标可能显示不出来，不影响功能。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

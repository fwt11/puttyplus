## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64-setup.exe` —— **Windows 版**：双击安装（装到
  `%LOCALAPPDATA%\Programs\PuTTYPlus`，不用管理员权限）

校验和见 `SHA256SUMS`。

**这一版最大的变化：左边合成一栏**

以前左边**恒占 570px**：连接列表 230 ＋ 文件面板 340 ⇒ 1200px 宽的窗口里，
终端只剩 **约 630px**；而且连接管理和文件浏览分居两处，得在屏幕两头来回找。

现在左边是**一个侧边栏**，页签是「**连接**」和「**文件**」：

- **「连接」页**：会话列表（最近 / 自定义 / ssh config 分组、过滤框、
  双击即连）＋ 凭据库状态标志；
- **「文件」页**：远程 / 本地文件列表（**当前这条连接**的那一份）。

⇒ 终端可用宽 **约 630px → 约 860px（＋36%）**；两件事也挨在一起了。

**新增功能**

- **侧边栏固定在主窗口左栏**：跨连接都在，**不会被拖走**（以前文件面板能拖成
  独立格，这一版起文件面板不再属于连接页的格子树）。
- **折叠 = 整栏收起**：收起来不占地方；**展开时回到上次看的那个页签**。
- **连接页里不再有文件面板** ⇒ 终端**占满整页宽**，切页时子标签栏也不再
  左右跳位（以前切到数据库页时页签栏会从 x≈340 跳到 x≈0，看着像界面坏了）。
- **切连接标签，侧边栏的「文件」页跟着换**：文件面板是**每条会话一个**
  ⇒ 切到另一台服务器，看到的就是那台的文件。
- **宽度只记一套**：侧边栏默认 **340px**、可拖、会记住；设置页里原来的
  「文件面板宽度」并进了「侧边栏宽度」。

**体验优化（全界面审核 15 项，P0 / P1 全关、P2 全做）**

- **Docker 列表的列不再被挤没了**：列宽按窗口宽分**四档**（宽 / 中 / 窄 /
  极窄），每档自带最小宽 ⇒ 窄面板里也还看得见「资源」列。
- **表单窗口不再一刀切**：每个页各自能滚 ⇒ 短页不再空一大片，长页不再被裁。
- **SFTP 失败不再「弹一次就没了」**：面板头常驻「重试」「详情」。
- **数据库工作台空态有主按钮了**：未连接时直接能「新建数据库连接…」。
- **欢迎页的能力卡不再「看着能点、点了没反应」**：改成说明卡，并加了小标题
  「这个应用能干什么」。
- **通知按级别分组**（失败 → 警告 → 信息 → 成功）；**传输队列**有了顶部摘要
  和「全部 / 进行中 / 失败」筛选，失败项能直接重传。
- **ER 图空态不再一片空白**：单表会给字段摘要，两个按钮都有可见结果。
- **浅色主题补了第三层表面**（面板与卡片原本同色）⇒ 层级看得出来。
- **按钮与错误色的对比度**按实际颜色算并钉住 ⇒ 不再「灰得看不清」。

**修复**

- **数据库建表的主键约束名以前是猜的** ⇒ 现在用服务器给的真名（MySQL 写
  `PRIMARY KEY (…)`）。
- **容器文件的报错只给一句原文** ⇒ 现在**分七类**并说人话，原文进 tooltip。
- **目录镜像的时间列表头被截断** ⇒ 每列有语义最小宽，完整值进 tooltip。
- **快速命令的空态原来占着列表里的一行**（会被误选中）⇒ 移出列表。
- **回放窗口里多出一道重复的分隔线**。
- **表单与按钮的对比度、浅色主题表面层级**都补了回归测试（三主题 ×
  三尺寸）。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- Windows 安装包**没有签名** ⇒ 第一次跑会被 SmartScreen 拦 ⇒ 点「更多信息」
  → 「仍要运行」（或「属性 → 解除锁定」）。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 侧边栏页签化
（连接 / 文件）· 终端左右 / 上下分屏 · 编辑器停靠位 · 布局持久化 · 数据库
工作台（PostgreSQL / MySQL，通道复用当前 SSH 连接）· 容器工作台（日志 /
终端 / 监控 / 文件 / 镜像 / compose，复用同一条 SSH 连接）· 凭据库
（argon2 + AES-GCM）· 中英文界面 · 会话录制与回放（asciicast）· 串口会话。

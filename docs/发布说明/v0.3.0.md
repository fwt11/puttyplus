## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— Debian / Ubuntu 等发行版的安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件
  （SSH 与加密全静态，只要目标机器有 GTK4 / VTE4）

校验和见 `SHA256SUMS`。

**本版要点**

- **界面可切中文 / English**：1610 条文案对照，设置里一键切换；菜单、快捷键、
  设置项、报错提示一并跟着切。
- **堡垒机场景干净**：从堡垒机拉起的一次性会话里，界面上不再出现「记住密码」，
  密码也不会悄悄落进凭据库。
- **页签标题不再被截断**：长标题按文字自然宽度显示，不再只剩「demo-s…」。
- **README 换成真机演示**：终端分屏 + 数据库工作台两张图都是真实运行的样子。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

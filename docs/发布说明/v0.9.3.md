## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64-setup.exe` —— **Windows 版**：双击安装（装到
  `%LOCALAPPDATA%\Programs\PuTTYPlus`，不用管理员权限）

校验和见 `SHA256SUMS`。

**这一版改了什么**

这一版是「**界面灵活化 + 瘦身**」这一轮收尾 ⇒ 连接页从「固定的左右两栏」变成
**一棵可以随便拆、随便拖、并且能记住形状的格子树**：

- **连接页可以拆格子**：一条竖分割条把它切成上下两半、把文件面板和终端拆到
  不同的格子、拖动终端页签到某个格子边上的任意位置就能再切一刀。落点会整块
  亮起来，还带一个方向箭头 ⇒ 不用精准对准，一眼看出会落在哪一边。
- **文件面板自己一格**：不再挤在终端那一栏里 ⇒ 想放左边放左边、放右边放右边，
  也可以拖到别的格子去。
- **布局会被记住**：关掉连接页时把格子形状（每格原来是什么）存进设置文件 ⇒
  下次连同一个会话**还原成一样的样子**。存的是**形状**不是内容 ⇒ SSH 会话
  / 数据库连接 / 打开的文件恢复不出来（那不是能存盘的东西）⇒ 那一格会给个
  提示页，**不假装恢复了内容**。
- **编辑器就是格子里的一个页签**：跟终端并列，想放哪儿拖到哪儿（拖到某条边
  ⇒ 那一侧生成新格子、编辑器进去）。
- ⚠️ **不再有「底部编辑区」**：以前编辑器可以「停在终端下面」，那一块在界面
  上白占终端列的下半、还挂着「把编辑器拖回这里停靠」的过时提示 ⇒ **这一版
  整个退役** ⇒ 停靠位只剩**主栏页签**与**左右侧栏**两个。
- **拖放之后界面不再跳位**：以前放完文件面板会突然变得很宽（分割条被重置
  成 GTK 的默认宽度）⇒ 现在分割条按「两侧的第一个叶子格子」这个身份记住
  位置 ⇒ 放完还是原来的宽度。
- **界面密度三档**：紧凑 / 标准 / 宽松，紧凑是默认。
- **容器列表重新排版**：容器名那一列不再占掉整行富余宽度（它本来就短）⇒
  省下的地方给「详情」列（以前「已退出（读出码 0）· 6 天」这类内容会被截断）；
  **端口改成一个端口一行**（以前一长串端口挤在一行里，被省略号截断）；
  **内存列只显示绝对值**（不再一格里塞「百分比 ＋ 绝对值」两个单位）。
- **「进入容器」弹出一个终端窗口**：以前终端嵌在容器面板的下半页 ⇒ 这一版
  改成**独立窗口**（像 Docker Desktop 的 Exec 那样）⇒ 可以一边看容器列表
  一边在窗口里敲命令；**Windows 与 Linux 一致**。

**上一版（v0.9.2）的主要内容**

- **「+」菜单里多了「容器…」**：页签栏最右端那个「＋」点开，现在有「新建
  终端」「新建数据库连接…」「容器…」三项 ⇒ **不用再去「连接」菜单里找
  容器**。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- Windows 安装包**没有签名** ⇒ 第一次跑会被 SmartScreen 拦 ⇒ 点「更多信息」
  → 「仍要运行」（或「属性 → 解除锁定」）。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 连接页格子自由拆分与拖放 · 编辑器两个
停靠位 · 布局持久化 · 数据库工作台（PostgreSQL / MySQL，通道复用当前 SSH
连接）· 容器工作台（日志 / 终端 / 监控 / 文件 / 镜像 / compose，复用同一条
SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 · 会话录制与回放
（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

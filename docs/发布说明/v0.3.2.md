## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）

校验和见 `SHA256SUMS`。

**本版要点**

这一版集中修「同一套代码在两台机器上表现不一样」的一类毛病——根子都在
**把该跟着人走的偏好记在了机器上**，或者**根本没在监听该监听的东西**。

- **数据库页的文件面板不再「这台机器有、那台机器没有」**：原来这个选择
  记在 `settings.ini` 里，跟着机器走。现在改成会话内状态——进数据库页
  默认收起（工作台要宽度），你在子标签栏用「文件面板」开关拉回来，就保持
  到关掉这个连接为止。**每台机器行为一致。**
- **结果网格的列宽不再冻住**：面板拉窄，右边那几列却一动不动。根因是
  GTK4 的控件压根没有 `width` 属性（那个宽度监听一次都没触发过，还在
  静默失败），而且宽度不够时旧逻辑会保持自然宽让滚动条出场。现在宽度
  不够就**按比例缩**（每列下限 60px），面板变窄、列跟着变窄。
- **数据库对象树改成单列（对标 dbx）**：名称与说明合成一串，省地方；树
  变窄时不再有「第二列冻住」的问题（以前两列各有 140px 下限，一挤就卡
  住）。图标换成**彩色 emoji**——库 / 模式 / 表 / 视图 / 列 / 索引 / 函
  数 / 存储过程 / 触发器 / 事件各一个，一眼分得出是什么对象。
- **SFTP 断了能自动重连**：以前 SFTP 那条连接断了没人知道，面板还显示
  「已连接」，直到你点刷新才弹一个「读取远程目录失败」，还得自己想到去点
  「重新连接 SFTP」。现在断了立刻在状态栏说明；**刷新 / 换目录时自动重
  连**，断着时输入的路径会记住、连上后自动跳过去；「重新连接终端」时也
  会把断掉的 SFTP 一起救回来。
- **文件编辑器的行号栏不再漏出「半个 emoji」**：彩色 emoji 不吃文本前景
  色，藏不住（以前是拿「画成底色」当隐形手段）。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**界面重做（这一版的主要变化）**

- **有形状了**：以前整套界面是 Adwaita 默认外观（直角、没有卡片、一个
  字号），现在有自己的设计令牌 —— 暗色主题分三层（窗底 / 面板 / 卡片），
  新增卡片、状态药丸、键帽、等宽四个可复用的原语，新界面直接套用。
- **状态是胶囊**：容器列表的「状态」列不再是纯文字，而是带状态色圆点的
  胶囊（运行中 / 已停止 / 报错各有各的颜色）。
- **表格有节奏了**：数字列右对齐、ID 与端口等宽、表头降半调、单元格内边距
  统一 ⇒ 扫一眼就能对上行。
- **图表精修**：监控曲线换了圆角卡底、渐变面积填充、圆角线帽与虚线网格。
- **欢迎页有门面了**：定位句升级成三张能力卡，常用键位键帽化。

**容器工作台**

- **容器表格能排序了**：每一列都能点表头排序，CPU / 内存按数值排。
- **容器行有右键菜单与快捷键**：进 shell、看日志、启停、重启、复制 ID。
- **空态与错态说人话**：出错时是一块大号说明（按原因分类 ＋ 重试按钮），
  不再是「一张空表 + 角落一行小灰字」。
- **状态行不说假话**：每个分段各记一份状态；过滤时写「显示 N / 共 M」。
- **概览页是四张键值卡**：不再互相裁；详情列不再残留英文（`Up 13 hours
  (healthy)` ⇒ `已运行 13 小时（健康）`）。
- **日志长行不再被截**：加「折行」开关、横向滚动条常显、还有「复制全部」。
- **镜像 / 卷 / 网络都能筛**：三页各带搜索框。
- **工具条瘦身**：拆成「筛选组 | 操作组」，去掉重复的刷新按钮。
- **容器终端搬进详情区**（多一个「终端」页签），错误弹窗也认宿主窗口了。

**编辑器**

- **可以停靠在三个位置**：主栏页签（默认，与终端并列）/ 底部 / 左右侧栏
  ⇒ 像 VS Code 那样拖着放。
- **页签标出「这个文件在哪台机器上」**：远程编辑的文件页签带电脑图标，
  本地文件带铅笔图标。
- **打开 compose 文件时，左边的 SFTP 会跳到项目目录并选中那个文件**
  ⇒ 看到的是「项目文件树 ｜ compose 编辑器」，一眼知道在编辑哪个文件。

**修复**

- **Windows 下本地面板的路径不再显示成 `\\?\C:\Users\…`**：那种逐字路径
  用户既不认也删不掉 ⇒ 现在显示成正常的 Windows 路径。
- **Docker 没权限时说人话**：以前只在底部一行小灰字里写「没权限」，
  现在弹窗说清原因（怎么把账号加进 docker 组）＋ 页面上常驻大号错态。
- **容器文件页瘦身**：目录 / 文件 / 链接各有各的图标（以前光看名字分不出
  是什么）；权限用通用的 `drwxr-xr-x` 写法（不翻译）；工具条两行并成一行
  的纯图标按钮（文字在悬停提示里）。
- **文件面板的软链图标一直是「缺图」**：原来用的图标名在 Adwaita 里不存在
  ⇒ 现在换成真有的那个。
- **点容器就是看那个容器**：选中一个独立容器时，底下不再挂着别的 compose
  项目的内容。
- **容器里没有 `ls` 时不再甩 docker 的原话**：直接说「这个容器里没有 ls
  命令 ⇒ 列不了目录」并给出两条出路。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- 图标主题没随包带 ⇒ 界面图标可能显示不出来，不影响功能。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 编辑器三停靠位 · 数据库工作台
（PostgreSQL / MySQL，通道复用当前 SSH 连接）· 容器工作台（日志 / 终端 /
监控 / 文件 / 镜像 / compose，复用同一条 SSH 连接）· 凭据库（argon2 +
AES-GCM）· 中英文界面 · 会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

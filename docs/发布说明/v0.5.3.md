## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**本版要点**

本版是一个大版本：**一个服务器只开一条 SSH 连接**（连接中枢），外加
**修掉了「上传大文件时整个界面卡死」**。

- **连接中枢：同一台服务器只开一条 SSH 连接**。现在 SFTP 文件面板、
  端口映射（`-L`/`-R`/`-D`）、数据库工作台、交互终端**全都走同一条
  SSH 连接**，只是各自开自己的**通道**：
  - SFTP 走 `subsystem sftp` 通道；
  - 端口映射走 `direct-tcpip` / `tcpip-forward` 通道；
  - 数据库走 `direct-tcpip` 通道；
  - 终端走 `session` 通道（申请 pty + shell）。
  ⇒ 连同一台服务器**只认证一次**、只占服务器一个连接位，服务器限制
  连接数时也不再被本程序自己占满。跨标签页也复用同一条。
  ⚠️ **终端并入共享连接后不再走你自己的 `ssh`** ⇒ `~/.ssh/config`
  （ProxyJump 等）不生效 ⇒ 需要的话在**首选项 →「终端」页 →「终端连接
  方式」**切回「spawn 自己的 ssh」（或设 `PP_TERM_SSH=spawn`）。
  ⚠️ **Windows 版**：PATH 里有 `ssh.exe`（或 `plink.exe`）就 spawn 它，
  一个都没有才走进程内 russh ⇒ 装了 OpenSSH 的机器行为跟 Linux 版一样。
- **修：上传大文件时界面整体卡死**（用户报「上传 1GB 文件时界面完全卡住、
  菜单都点不动、进度停在 2% 然后突然跳到 80%」）。根因有两个，都修了：
  - 进度更新和呼吸动画**每帧把整个文件列表重画一遍**（每个可见行都要
    重新排一次文字）⇒ 主线程一帧 59ms ⇒ 远程桌面上再乘一个往返 ⇒
    界面冻住。现在**只重画正在传的那一行**，进度通知**限流到每 100ms
    一次**（数字不会丢）；实测一帧的绘制量从 5727 次降到 39 次。
  - 传输与面板请求**挤同一条 SFTP 通道**（SSH 的通道窗口是每通道一份）
    ⇒ 大文件吃光那条通道的窗口，服务端连目录列表都回不来。现在**传输
    走自己那条通道**（**仍然是同一条 SSH 连接**，不多占服务器连接数）。
- **传输队列按钮的角标重做**：数字画在一个**蓝色圆点**里，**外面套一个
  真的在转的圈** ⇒ 一眼就知道「还在传」，数字告诉你「还剩几件」；传完
  圆点连数字一起消失，不留空蓝块。

**其它改进**

- **Windows 版**：数据库工作台与端口映射**开放**（不再藏入口）；端口映射
  由程序内引擎承接（不再是「装了 OpenSSH 就静默失效」）；ConPTY 的
  UTF-16 编解码修正（中文不再乱码）。
- **终端引擎可切换**：ghostty 变成默认引擎（Linux 也一样），**首选项 →
  终端**里可以选 libvte 还是 ghostty（只对新开的终端生效；Windows 上
  那一项不显示 —— 那边没有 VTE）。
- **编辑器**：查看上限改成**可配置**（首选项 →「高级」页，1–64 MB）；
  非文本文件可以「以 hex 模式打开」（先问用户，同意才开）。
- **文件面板**：大小列按这一批文件里**最长的那个**定宽（保证完整显示）；
  横向滚动条**自己画**（好抓）；传完的「完成」显示一会儿再慢慢消失；
  正在传的文件行背景会「呼吸」。
- **选中态的底色不再压住文字**（首选项按钮 + 文件列表选中行都修了）；
  数据库列头的「⋯」换成齿轮（那个看着像菜单）。

**Windows 版的已知差异**（Linux 版不变，仍然 spawn 用户自己的 `ssh` ⇒
`~/.ssh/config`、agent、ProxyJump 的语义全都在）：

- Windows 版终端**不读 `~/.ssh/config`**（别名由本程序自己展开，
  `HostName`/`Port`/`User`/`IdentityFile` 生效，但 **ProxyJump 不支持**）；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发走本程序自己的进程内转发，不经 `ssh -L/-R/-D`。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

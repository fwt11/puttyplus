## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）

校验和见 `SHA256SUMS`。

**本版要点**

- **文本编辑页也带上文件面板**：编辑远程文件时，左边照样能浏览目录、点另一
  个文件换着编辑，不用来回切换页签。文件面板是会话级的同一个面板，跟着
  「当前那一页」走：终端页与编辑页都带它，数据库工作台页仍是整页接管宽度。
- **关掉编辑器页签不再连带弄丢文件面板**：托管文件面板的容器现在由面板状态
  持有一份强引用（GTK4 中容器被销毁时会一并销毁其子控件）。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

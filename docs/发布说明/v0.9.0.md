## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**新增功能**

- **容器日志实时可见**：容器详情里多一个「日志」页，边收边看 `docker logs`
  的输出，带搜索、暂停 / 继续、自动跟随与清空。
- **能直接进容器**：容器列表上方有「进入容器」按钮，双击容器行同样可以，
  等价于 `docker exec -it` —— 进去的终端带 TTY，窗口尺寸跟着走，Ctrl-C
  也管用。
- **容器内终端有工具条**：换 shell（点名要 sh / bash / ash / zsh）、重连、
  清屏、搜索输出；搜索条与主终端、编辑器是同一套外观与按键约定。
- **容器监控曲线**：容器详情里多一个「监控」页，CPU、内存、网络、磁盘
  四张实时折线图。
- **容器里的文件能看也能传**：详情里多一个「文件」页，浏览目录、查看文件
  内容，上传 / 下载文件与目录；传输走 Docker 官方归档流 ⇒ 二进制不走样，
  容器里不需要装任何工具。
- **镜像、卷、网络都能列出来**：容器页顶部分成四段（容器 / 镜像 / 卷 /
  网络），切过去才取数据。
- **镜像能推、能导出、能打标签、能删除**：镜像表格正上方一条操作条，每个写
  操作都有二次确认，失败给中文原因。
- **文件管理器能按文件名过滤**：面板第一行有个 🔍，点开输个词就只看名字带
  它的文件（不分大小写），远程面板与本地面板各管各的。
- **容器页打开时不再空着**：正在取数据时列表正中间有转圈，工具条上也有
  小转圈。
- **编辑 compose 文件后当场就能看到**：编辑器不再躲在终端页里，直接显示在
  容器页下方（同窗、马上可见）。

**体验优化**

- ghostty 后端现在有两个行为跟 libvte 对齐了：敲键（输入法提交、粘贴）后
  画面自动回到最底下；终端里的查找（Ctrl+F）真的能看见高亮（以前搜完
  什么也没发生）。
- 编辑器搜索不再把被搜的内容拽到屏幕最左边：匹配已经在可视区里就一点都
  不动，用户自己滚到的位置也不会被拉走。
- 编辑器与终端的查找条：回车跳下一个匹配，Shift+回车跳上一个，Esc 关闭。
- 远程命令的退出码不再恒为 0 ⇒ 失败现在能拿回真实退出码。
- 断网后光标不再一直闪。

**修复**

- 镜像自动刷新会把选中的镜像冲掉 ⇒ 按钮变灰、正要点的操作点不动，现在按
  名字找回复选中项。
- 容器详情与启停按钮点了没反应（详情区永远不显示）。
- 刷新容器列表会清掉光标 ⇒ 刚选中的容器一刷新就没了。
- 关掉日志 / 监控流后，服务器上会残留 `docker logs` / `docker stats` 进程。
- 远程命令结束后退出码包还没送到就被丢掉 ⇒ 退出码永远是 0。
- 容器里没有 shell 时探测也报「有」（探测从来没真的试过）。
- 传输卡住时界面会一直显示「正在上传…」，且挡住后续传输。
- Linux 主终端的 Ctrl+F 搜索从来没生效过（正则的用途建错了，被 VTE 当场
  拒收）。
- 容器内上传下载用的不是 `docker cp` 的归档流 ⇒ 二进制文件传过去会坏。
- 断网后光标还在一直闪。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- 图标主题没随包带 ⇒ 界面图标可能显示不出来，不影响功能。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 容器工作台（日志 / 终端 / 监控 / 文件 / 镜像，
复用同一条 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

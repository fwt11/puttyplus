## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台 + 容器工作台（Linux / Windows）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86_64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64-setup.exe` —— **Windows 版**：双击安装（装到
  `%LOCALAPPDATA%\Programs\PuTTYPlus`，不用管理员权限）

校验和见 `SHA256SUMS`。

**新增功能**

- **容器页的「操作」列只留三颗图标**：启动 / 停止 / 重启 ⇒ 一眼能分清；
  其余动作（**进入容器**、**文件**、**日志**、**属性**、编辑 compose 文件、
  销毁、重建、复制容器 ID）全部搬进**右键菜单** ⇒ 右键哪一行，菜单就针对
  哪一行（容器行与 compose 项目行的项**不一样**）。
- **右键菜单新增三个入口**：**文件**（直接看容器里的文件）、**日志**、
  **属性**（对应原来的「详情 / 概览」）。
- **容器状态列显示时长**：运行中显示「运行 2 小时」，只是创建了就显示
  「创建 3 分钟」，已停止显示「停止 1 小时」⇒ 不用再点进去看详情。
- **每条连接各自记住本地目录**：在 A 服务器下载到 `/data`，切到 B 服务器
  不会跟着跳过去。
- **SSH 连不上时给一句人话**（超时 / 认证失败 / 网络不通 / 不知道），
  并带一颗「重连」。

**体验优化**

- **容器页改成一张满高的列表**：概览 / 日志 / 监控 / 文件都搬进弹窗 ⇒
  列表能占满整页；弹窗里有「关闭」按钮，**Esc 也能关**，关掉再打开内容
  还留着。
- **「操作」列的图标看得见了**：以前是一排几乎看不见的灰糊点 ⇒ 现在按
  主题染色（浅色主题深色图标 / 深色主题浅色图标），播放 / 停止是自绘的
  描边图标 ⇒ 整排是同一套语言；**悬停有说明**，灰掉的图标会说明「为什么
  不能点」。
- **各列宽度按内容重排**：容器名称列不再占掉整行富余宽度（它本来就短），
  镜像名不再被省略号截掉，端口一个一行，状态药丸带时长 ⇒ 各列之间比例
  合理。

**修复**

- **双击容器里的文件夹时，地址栏里的路径会越拼越长、进不去目录** ⇒ 以前
  把「空目录」当成失败，表格停在上一级，而地址栏却往前跑 ⇒ 现在进得去，
  地址栏也不会再累积（失败时它会退回上一个成功的目录）。
- **运行中的容器有时不显示时长** ⇒ docker 对「跑了一小时上下」的容器给的是
  `Up About an hour` ⇒ 以前没认出这句 ⇒ 现在「运行 1 小时」照常显示。
- **右键菜单里「启动 / 停止」是两个灰糊的缺图** ⇒ 那两个图标是表格里**自绘**的
  ⇒ 菜单里得用系统主题真有的图标名 ⇒ 现在是 ▶ 和 ■。
- **打完标签 / 删掉镜像后列表不更新**（状态行说删了，表里那行还在）⇒
  刷新撞上正在取的那次会被丢掉 ⇒ 现在撞上了会**自动再刷一次**。
- **compose 项目行的「启动 / 停止」以前是坏的**（把项目名当容器名去停）
  ⇒ 现在走 `docker compose`，项目也能整体重启了。
- **容器页「操作」列点图标会命中下面那一行** ⇒ 点 compose 项目行的按钮却
  弹出了别的容器的终端窗口。
- **容器详情弹窗关不掉** ⇒ 以前只能杀掉整个窗口。
- **容器状态药丸永远是灰的** ⇒ 现在按真实状态分绿 / 灰 / 红。

**Windows 版的已知差异**

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- Windows 安装包**没有签名** ⇒ 第一次跑会被 SmartScreen 拦 ⇒ 点「更多信息」
  → 「仍要运行」（或「属性 → 解除锁定」）。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 连接页格子自由拆分与拖放 · 编辑器两个
停靠位 · 布局持久化 · 数据库工作台（PostgreSQL / MySQL，通道复用当前 SSH
连接）· 容器工作台（日志 / 终端 / 监控 / 文件 / 镜像 / compose，复用同一条
SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 · 会话录制与回放
（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。

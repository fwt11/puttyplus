## PuTTYPlus {{VERSION}}

PuTTY 兼容的 SSH 终端 + 图形化 SFTP + 数据库工作台（Linux / GTK4）。

**下载**

- `puttyplus_{{VERSION}}-1_amd64.deb` —— x86-64 的 Debian / Ubuntu 等发行版安装包
  （依赖 GTK ≥ 4.18、VTE ≥ 0.80）
- `puttyplus_{{VERSION}}-1_arm64.deb` —— arm64（aarch64）同上，树莓派 / ARM
  服务器 / ARM 笔记本用这个
- `puttyplus-linux-x86_64.tar.gz` —— 免安装的单个可执行文件（x86-64）
- `puttyplus-linux-aarch64.tar.gz` —— 免安装的单个可执行文件（arm64）
- `puttyplus-windows-x86_64.zip` —— **Windows 版**（实验）：解压后双击
  `puttyplus.exe` 即可（GTK 的 DLL 都在包里；图标主题没带，可能显示不出
  图标，不影响功能）

校验和见 `SHA256SUMS`。

**本版要点**

- **ghostty 引擎（Windows 版的默认引擎）支持鼠标拖选复制**：按住**左键**
  在文字上拖一下就能选中，选中的地方**真反白**（底色与文字互换，跟 libvte
  观感一致）；「复制」把选中的文字放进**系统剪贴板**；单击别处取消选中。
  ⚠️ 以前这个功能是**空函数** ⇒ Windows 上根本没法把终端里的文字复制出来
  （Linux 用 libvte 一直有，不受影响）。
- 顺带修一个真问题：以前选区**只反底色、不反文字** ⇒ 默认色的文字就是
  「**白底白字**」⇒ **选中的内容根本看不见**（像素级验证：选中区域的颜色
  只有一种；修完是 144 种）。
- ⚠️ 拖选只在**当前看得见的行**里选（还没做「滚视口选历史行」）。

**上一版（0.7.0）的内容照旧**：Linux 默认也并入「一台服务器一条 SSH 连接」
（libvte 后端也能走进程内 SSH ⇒ 密码只问一次、只占服务器一个连接位）；
结果网格「生成值…」（序列 / UUID / 当前时间 / 当前日期 / 随机数，值由数据库
算）与「列宽拖拽柄」（记住你拖出来的宽度）；ghostty 引擎补齐三件（回滚行数
上限生效、自定义配色生效、录制 asciicast 可用）。详见
[v0.7.0 的说明](https://github.com/fwt11/puttyplus/releases/tag/v0.7.0)。

**再上一版（0.6.0）的内容照旧**：数据库工作台对标 SQLite 客户端 dbx 重做一遍
——筛选就是一个宽 WHERE 框写完回车查、旁边 ▾ 条件助手按列类型转义；
工具条收回一行、底栏报账（行数·耗时·待保存 / 常驻当前 SQL / 统计总行数
真值）；表属性页多一段只读可复制的「建表语句」。

**Windows 版的已知差异**：

- 终端默认并入共享连接：不走你自己的 `ssh` ⇒ `~/.ssh/config`（别名、
  ProxyJump）与 agent 不生效 ⇒ 需要「spawn 自己的 ssh」在首选项里切；
- Windows 上数据库走回环 TCP ⇒ 远端 `pg_hba.conf` 需要放行 TCP + 密码
  认证（Unix 那边走本地套接字，多半是 peer/trust，不校验密码）；
- 端口转发由本程序的进程内引擎承接（不经 `ssh -L/-R/-D`）；
- 图标主题没随包带 ⇒ 界面图标可能显示不出来，不影响功能。

**特性**：命令行与 PuTTY 兼容（可顶替 PuTTY 部署在堡垒机上）· 终端 + SFTP
双栏同窗口 · 终端左右 / 上下分屏 · 数据库工作台（PostgreSQL / MySQL，
通道复用当前 SSH 连接）· 凭据库（argon2 + AES-GCM）· 中英文界面 ·
会话录制与回放（asciicast）· 串口会话。

详见 [README](https://github.com/fwt11/puttyplus#readme)。
